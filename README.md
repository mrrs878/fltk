# QuickADB

一个ADB的图形化工具，基于webview框架开发，支持Windows和Linux平台。

## 主要功能

1. 设备管理：连接、断开和查看已连接的ADB设备。

2. 应用管理：安装、卸载和查看设备上的应用程序。

3. 文件传输：在本地计算机和ADB设备之间传输文件。

4. 命令执行：直接在ADB设备上执行ADB命令。

5. 日志查看：实时查看设备日志输出。
